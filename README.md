# Cyber Security Internship - Task 2
**Topic:** Operating System Security Fundamentals (Linux & Windows)

## Overview
This repository contains my submission for Task 2 of the Cyber Security Internship. The focus of this task was to explore Operating System hardening, understand file permissions, and learn how to reduce the attack surface on both Linux and Windows environments.

## Summary of Learning
In this task, I explored the following OS security concepts:
* **User Account Management:** The critical difference between **Root/Administrator** and **Standard Users**, and why the "Principle of Least Privilege" is essential.
* **File Permissions:** How to read and modify permissions using Linux commands like `chmod`, `chown`, and `ls -l` to secure sensitive files.
* **Network Security:** Configuring firewalls (using **UFW** on Linux and **Windows Defender**) to block unauthorized access.
* **Attack Surface Reduction:** The importance of disabling unnecessary services and closing unused ports to minimize potential entry points for attackers.
* **OS Hardening:** Best practices for securing an operating system immediately after installation.

## Tools & Commands Used
* **Operating Systems:** Ubuntu Linux & Windows
* **Commands:** `chmod`, `chown`, `ls -l`, `sudo`, `ufw`, `systemctl`
* **Security Tools:** Windows Defender Firewall
